## Project Overview

**Repository:** https://github.com/iamridwansec/Azure-Cloud-Basics-and-IAM

### Project Description

Completed a hands-on cloud security learning project using Microsoft Azure for Students. Configured and reviewed foundational cloud security controls covering account security, Microsoft Entra ID, Azure Role-Based Access Control (RBAC), activity monitoring, budget alerts, and Azure Storage protection.

Validated selected configurations using Azure CLI and documented security findings, limitations, evidence, and recommendations.

### Work Performed

- Reviewed Azure subscription security and privileged access assignments.
- Enabled Microsoft Entra Security Defaults and inspected account security information.
- Examined Azure RBAC permissions and prepared custom least-privilege role definitions.
- Reviewed Azure Activity Logs and subscription diagnostic settings.
- Configured a monthly Azure budget with 50%, 80%, and 100% notification thresholds.
- Created an Azure Storage account and private Blob container.
- Configured HTTPS-only access, TLS 1.2, disabled anonymous Blob access, and disabled Shared Key authorization.
- Disabled SFTP and reviewed storage network restrictions.
- Tested unauthenticated container access and recorded the HTTP 403 response.
- Produced technical documentation, validation results, and security recommendations.

### Project Limitations

This was a learning and configuration assessment in an Azure for Students environment. Custom roles were drafted but not deployed, individual MFA completion was not independently verified, and Activity Log event collection was not fully validated. These limitations are documented in the repository.
